What this server is one job, real money

A live MCP wrapper around Lemma — the healthcare-practice banking platform Helen's entity banks with. It lets an agent read accounts, transactions, lockbox mail, check deposits, insurance remittances (835 ERAs), and cards directly, and — only when deliberately unlocked — move money (ACH / book transfers), issue cards, and save external payment recipients. It is the live counterpart to the separate lemma_docs_mcp, which only answers "how does the API work" from a small local doc corpus and never touches a real account.

lemma_docs_mcp ("how does this work?") · read-only local corpus  ⟷  lemma-banking-mcp (this server) · executes live against api.getlemma.com

Safety gate every write passes through both checks

Blocked by default

This is a live money-movement API. The 5 write tools are registered but refuse to run unless LEMMA_ENABLE_WRITES=true is set in the server's environment and the individual call passes confirm: true. Read tools need neither. Even fully enabled, every write tool's description tells the calling agent it moves real money or creates a real financial instrument — the MCP being callable does not waive Claude's own explicit-confirmation rule for financial actions.

Every POST additionally carries a mandatory Idempotency-Key, derived deterministically from a caller-supplied reference — a retried call with the same reference replays the original result instead of double-paying. POSTs are never auto-retried by the HTTP layer; only GETs back off on 429.

Wiring it up

~/Library/Application Support/Claude/claude_desktop_config.json → mcpServers → "lemma-banking-mcp": { "command": "/absolute/path/to/node", "args": ["/absolute/path/to/lemma-banking-mcp/build/index.js"], "env": { "LEMMA_API_KEY": "<platform key from the Lemma team>", "LEMMA_ENABLE_WRITES": "" } } Find your node path with `which node` -- GUI apps don't inherit shell PATH, so the absolute path is required. Blocker: LEMMA_API_KEY is a *platform* key issued manually by Lemma, not a self-serve dashboard key. Email contact@getlemma.com to request one — until then every tool call returns a clear "not set" error instead of failing silently. Leave LEMMA_ENABLE_WRITES empty for read-only (the safe default).
